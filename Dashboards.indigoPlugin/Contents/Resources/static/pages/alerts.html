How this works

The plugin watches these rules on the Indigo server itself, so they fire whether or not any dashboard is open, and tells you by Pushover (through the Pushover plugin), by email (Indigo's own mail settings), or both. Tick Browser on a rule as well and any device showing the hub, a room page, Energy or this page also raises a notification; that part still needs one of those pages open, and an https address. Each rule waits thirty seconds before it fires again, so a chattering sensor cannot flood you.
